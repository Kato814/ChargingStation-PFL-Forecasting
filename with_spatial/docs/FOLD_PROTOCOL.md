# 五折目标站轮换与折级参数

论文主实验采用5折站点轮换。每折：

- 2座目标/测试站；
- 下一目标站对作为2座验证站；
- 其余36座站点作为联邦训练站；
- 同折2座测试站构成一个独立同期部署组，用于站群总量校正和部署组聚合评价。

## 固定公共参数

- 站群总量校正历史窗口：5 d；
- 站群校正正则化：0；
- `gamma_max=1`；
- 近期表现窗口：10 d；
- 近期表现容忍阈值：`delta=-0.02`；
- 累计损失预算：3%；
- 初始观测/预热期：7 d。

## 时间边界

- 训练期：2022-09-02—2022-12-15；
- 验证期：2022-12-16—2023-01-15；
- 测试期：2023-01-16—2023-02-28；
- 测试日真实负荷仅在该日预测完成后进入后续滚动状态。

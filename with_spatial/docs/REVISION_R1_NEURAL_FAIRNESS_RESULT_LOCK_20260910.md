## 4. 论文解释边界

1. 站群校正和风险控制对多种预测器具有通用价值，不能把全部性能收益归因于 PFL。
2. 本文方法的最终性能来自共享残差建模、目标站低自由度个性化、站群协调和风险控制的协同作用。
3. 固定后处理实验使用相同冻结参数，不代表每个基线均获得其各自最优的后处理调参。
4. 在统一固定后处理后，本文方法相对 FedProx 和 FedRep 仍保持较低 WAPE，且 44 日时间轴差异具有统计支持。
5. 仍不得声称本文方法在统一后处理后“显著优于所有基线”：既有全参数微调和 pFedMe 的 Newey-West 结果不支持该表述。
6. FedRep 在当前未参与共享训练目标站协议下仅 2/10 站点获得原始改善；该结果按预注册协议保留，不进行测试后重调。

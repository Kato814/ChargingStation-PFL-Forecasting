# R1返修补充实验协议（2026-09）

## 1. 目的与冻结边界

本协议仅服务论文《基于个性化联邦学习的多类型充电站负荷预测及负迁移抑制方法》一审返修。

V1.0 `main` 与 `v1.0-archive` 保持冻结，不修改原539维输入、五折划分、主方法形式、折级参数、站群校正参数、负迁移参数和正式评价口径。所有返修补充实验仅在 `revision/r1-202609` 分支开发，新增结果不得覆盖 `results_reproduced/` 与 `results_reference/` 中的V1.0记录。

返修新增结果统一写入：

`with_spatial/results_revision_r1/`

正式论文结果以用户本机基于SHA匹配的539D冻结档案重新运行并通过核验后的结果为准。云端运行仅用于脚本开发、轻量试跑和逻辑检查；GitHub Actions仅承担轻量CI，不承担正式神经网络训练。

## 2. 固定数据与评价协议

- 输入：539维 `with_spatial` 冻结输入；
- 40座充电站；15 min分辨率；每日96点；
- 训练：2022-09-02—2022-12-15；
- 验证：2022-12-16—2023-01-15；
- 测试：2023-01-16—2023-02-28；
- 五折：每折36训练站 + 2验证站 + 2测试站；
- 同折2座测试站保持独立部署组边界；
- 测试期OOF逐点记录总数：42240；
- 正式主指标：总体聚合WAPE、nRMSE、站点改善数、最坏站点相对退化率；
- 日级统计：五折两站部署组边界下的44日配对序列，7 d循环移动块Bootstrap及Newey-West(lag=7)。

任何补充实验不得重新引入已废弃的跨折10站日级直接聚合口径。

## 5. R1-E2：统一后处理公平性实验

对应审稿人2意见4。

目的：分离“基础预测器质量”与“站群校正/风险控制”的贡献。

### 5.1 输入方法

仅使用当前已有逐点OOF证据的方法：

- FedAvg残差；
- 全参数微调；
- 本地MLP；
- pFedMe微调。

本地滚动岭回归因无逐点OOF，不参与该补充实验。

### 5.2 处理层级

对每个基线分别计算：

1. 原始预测；
2. `+group`：把该基线预测视为站点候选，以前日基准为anchor，施加与本文完全相同的5 d站群总量校正；
3. `+group+risk`：在2的基础上施加与本文完全相同的近期表现约束、累计损失约束、基准回退和修正量重分配。

禁止为任何基线重新调 `gamma`、`delta`、`beta` 或预热期。

### 5.3 输出

- 总体聚合WAPE、nRMSE；
- 全样本WAPE；
- 改善站点数；
- 最坏站点相对退化率；
- 本文最终方法相对各“+group+risk”基线的部署组日级配对统计。

解释规则：如果统一后处理显著改善基线，应明确承认站群校正/风险控制具有通用贡献；若本文仍保持更低误差，则说明基础共享残差先验及低维个性化仍有独立贡献。不得预设“显著优于所有统一后处理基线”。

## 6. R1-E3：负迁移工况分析

对应审稿人1意见5。

不重新训练模型。以“站点×预测日”为基本单位，对V1.0 OOF的标量个性化候选、站群校正候选和最终风险控制结果进行机制分析。

### 6.1 当日负迁移定义

相对于前日同刻基准，若某站某日候选预测的绝对误差/WAPE增加，则记为该阶段当日负迁移。

### 6.2 工况分类

至少统计：

- 个性化候选与站群候选均改善；
- 个性化候选退化、站群校正后修复；
- 个性化候选改善、站群校正后退化（站群收益—单站收益冲突）；
- 两阶段均退化；
- 近期表现允许但累计损失约束最终关闭的持续风险场景。

同时按预测日前历史波动程度、前日基准竞争强度和共享候选历史误差进行分层。所有“工况解释变量”若用于因果/预测机制说明，应优先使用预测日前历史计算；若使用当日真实负荷，只能明确标注为事后诊断变量。

### 6.3 输出

- 工况数量/比例表；
- 各阶段负迁移站点日比例；
- 风险控制前后最坏站点退化变化；
- 1幅简洁机制图或统计图（如正文篇幅不足，详细结果放Response Letter/补充材料）。

## 7. R1-E4：滚动标量系数alpha统计含义

对应审稿人2意见5。

不重新训练共享模型。

### 7.1 主要关系

以站点日 `alpha_{j,d}` 为响应量，计算与以下量的关系：

1. 预测日前历史窗口内共享残差候选的误差；
2. 共享残差候选相对前日基准的历史收益；
3. 预测日前近期负荷波动率；
4. 站点类型；
5. 有效历史样本量/历史窗口。

连续变量优先报告Spearman相关，并同时报告站内相关分布，避免由站点间尺度差异造成伪相关。

### 7.2 样本量补充分析

冻结主方法不改H。另做受控补充分析：共享模型保持固定，仅以 `H in {7, 14, 30, 60}` 重新估计alpha，用于考察历史长度对alpha波动性和统计关系稳定性的影响。该分析不得替代V1.0正式H取值，也不得据此重新选择论文主参数。

### 7.3 解释边界

alpha定义为共享残差与目标站近期真实跨日残差之间的正则化投影/缩放系数。不得把alpha解释为静态站点质量指标，也不得把相关关系写成未经验证的因果关系。

## 8. R1-E5：三类目标站稳健性补充

对应审稿人1意见6中的“多类型普适性”。

不新增第二数据集，不扩大到未经协议设计的40站全轮换。

对快充、慢充、混合三类分别报告：

- 类型聚合基准WAPE；
- 本文类型聚合WAPE；
- 相对改善；
- 改善站点数/总数；
- 类型内最坏站点相对退化；
- 保持五折部署组边界的类型级日差Bootstrap CI和Newey-West结果（如样本结构允许稳定计算）。

论文结论限定为“本数据集覆盖的三类目标站均获得正向类型聚合收益”，不得扩大为跨数据集普适性证明。

## 9. R1-E6/R1-E7：新增主流联邦基线

对应审稿人1意见6。

### 9.1 方法选择

新增：

- **FedProx**：代表面向统计异质性的经典联邦优化方法；
- **FedPer**：代表共享表示+本地个性化层的经典个性化联邦方法，并与当前已有pFedMe形成互补。

选择原则：当前稿件引言已讨论FedProx；当前引用的多区域个性化联邦负荷预测研究使用FedPer/pFedMe作为代表性PFL对照，因此FedProx+FedPer比继续增加普通集中式深度模型更直接回应审稿意见。

### 9.2 共同神经网络协议

尽量沿用V1.0神经网络基线锁定协议：

- 539-128-128-96残差MLP；
- 第一隐层后LayerNorm；
- ReLU；
- dropout=0.08；
- 共享训练30轮；
- 每轮每客户端1 epoch；
- batch size=64；
- shared lr=8e-4；
- weight decay=1e-4；
- 目标站本地历史窗口=30 d；
- 目标站适配步数=3；
- target lr=5e-4；
- gradient clip=5；
- 随机种子：20260612、20260613、20260614；
- 三个种子独立运行后逐点取均值，再进入论文评价。

输入与预测目标必须与现有神经网络基线一致：539维输入、96维跨日残差输出，最终负荷=前日基准+残差并非负截断。

### 9.3 训练框架校准

在正式运行FedProx/FedPer前，先用同一新训练框架重跑FedAvg作为sanity calibration。若新框架FedAvg与V1.0锁定FedAvg结果存在明显偏离，不得直接继续并声称新基线可比；应先核查输入标准化、客户端权重、优化器、随机种子和预测后处理。

V1.0锁定FedAvg WAPE=0.101615（四舍五入0.1016）作为校准锚点，但不要求位级复现历史神经网络结果。

### 9.4 FedProx

局部目标：

`F_k(w) + (mu/2) * ||w - w_global||^2`

除proximal项外保持FedAvg训练预算一致。`mu`仅在每折验证站上从预先固定的小网格选择，测试站不得参与选择。候选网格在代码实现前固定，不因测试结果调整。

### 9.5 FedPer

保持与共同MLP相同总结构；共享表示层参与联邦聚合，个性化输出层仅在本地训练。部署到未参与共享训练的目标站时，共享表示保持固定，目标站使用预测日前30 d历史训练/滚动更新个性化层。共享/个性化层划分在正式测试前固定，不根据测试结果改变。

### 9.6 新基线输出

每种方法必须保存：

- 三个种子的逐点OOF；
- 三种子逐点平均OOF；
- 每折训练日志与验证选择记录；
- 总体WAPE/nRMSE；
- 站点结果与最坏退化；
- 分类型结果；
- 与本文方法的部署组日级配对统计。

新基线不自动施加本文站群校正和负迁移控制；如需统一后处理，只进入R1-E2的独立公平性实验，不能与原始基线结果混写。

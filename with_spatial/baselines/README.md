# 表2对比方法代码与结果边界

本目录服务论文表2对比实验。

- `reference.py`：从锁定逐点OOF结果复算表2；
- `protocols.py`：冻结神经网络结构、随机种子和目标站历史窗口；
- 神经网络本地更新（全参数微调、本地MLP、pFedMe微调）：30 d；
- 本地滚动岭回归：60 d。

论文主方法本身可从539维输入、联邦充分统计量到最终五折预测完整端到端复现。

表2神经网络对比方法的最终逐点预测已作为实验记录保存在 `results_reference/oof_predictions_source.csv.gz`，用于稳定复现论文数值。当前整理版不把早期Stage/FedProx实验工程整体搬入主目录。后续若需要重新训练神经网络对比方法，应按 `protocols.py` 的冻结协议另开实验版本，并与当前锁定结果比较后再升级。
